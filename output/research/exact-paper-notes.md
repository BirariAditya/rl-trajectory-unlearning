# Exact Unlearning in Reinforcement Learning: reading and project notes

Source read: supplied `2606.04182v1.pdf`, 24 PDF pages, Thanh Nguyen-Tang and Raman Arora. Page numbers below are PDF page numbers, equal to the printed numbers. The supplied version labels itself ICML 2026 / PMLR 306 on p. 1. The [author's publications page](https://thanhnguyentang.github.io/) also lists ICML 2026. The [arXiv record](https://arxiv.org/abs/2606.04182) is dated June 2, 2026. Status checked September 19, 2026.

## 1. What the paper actually solves

An online learner sees one user episode at a time, chooses a policy, and receives statistics from the resulting trajectory. A later request replaces one episode with a fixed dummy episode. Its unlearning algorithm must produce an output distributed exactly as a fresh run of the SAME randomized learning algorithm on the modified sequence.

The learner's output is formally a sequence of policies plus auxiliary metadata, not merely its final policy. Definition 2.1 (p. 4) requires, for every fixed user sequence and replacement,

\[
U(A(z_{1:T}),z_t,z') \overset{d}= A(z_1,\ldots,z_{t-1},z',z_{t+1},\ldots,z_T).
\]

This is distributional equality over algorithmic randomness. It does not mean that one unlearning run has numerically identical weights to an independently seeded retraining run. It also does not mean deliberate failure on every behavior appearing in the deleted trajectory: retained data can legitimately teach the same behavior.

The fixed replacement preserves episode indexing and tree structure. A zero/no-op dummy is one possible designer choice, but deletion of an index with time compaction is a different comparator unless equivalence is shown.

### Environment assumptions that matter

- One fixed finite-state, finite-action MDP; horizon H; reward samples in [0,1]; transition/reward kernels can depend on the within-episode step h (p. 4).
- A user is an episode label. It is explicitly NOT a latent parameter defining a different MDP for each user (p. 4).
- The environment oracle is `x_t = EO_t(z_t; w_1:t)`, so feedback can change when the policy history changes (pp. 3–4).
- Footnote 1 on p. 4 represents a user as a depth-H response tree containing responses to all possible action sequences. This is richer than a single observed trajectory.
- The user sequence is oblivious to the learner; deletion time T is independent of the learner (p. 5). The formal result is one replacement request, not a developed repeated adaptively selected deletion theory.

### Offline versus online counterfactual

For a fixed offline dataset, retraining on D_retain means keeping all retained logged trajectories fixed. This is feasible without contacting the original users.

For this paper's online counterfactual, replacing episode t can alter policies and therefore the trajectories generated by later users. Upon a coupling failure the algorithm replays a suffix through the environment oracle. This requires counterfactual responses or a replayable environment. Merely retaining realized later trajectories does not provide those responses. In a simulator, response trees can be represented by reproducible exogenous random variables keyed to state/action/step; replaying a simple RNG stream without a specified coupling is not automatically the same comparator.

The paper's regret guarantee concerns its deliberately designed learner. It is not an after-the-fact deletion method for arbitrary previously trained DQN/PPO agents.

## 2. TV stability versus exact unlearning

Definition 2.2 (p. 5): changing one user in the input changes the learner's output distribution by at most rho in total variation (TV).

\[
\operatorname{TV}(A(Z),A(Z'))\leq\rho.
\]

TV is the largest change in the probability of any measurable output event. Small rho says the two output distributions overlap substantially. Maximal coupling can reuse the old sample on that overlap, correcting it only when necessary.

Rho is a stability / efficiency / learning-utility parameter. It is NOT the unlearning approximation error. The unlearning output is exact in distribution even when rho is positive; a smaller rho means more overlap, hence fewer expensive reruns, but requires more training-time noise.

The paper also explicitly says TV stability is not necessary for every possible unlearning method (p. 9). For example, exact algebraic subtraction of sufficient statistics can support unlearning without making the original deterministic learner TV stable.

## 3. Algorithm intuition

### During original training (Algorithms 1–2, pp. 5–6)

1. Turn each trajectory into an additive vector x_t: state-action visit indicators, transition indicators, and reward sums.
2. Store these vectors in a binary tree. Each node summarizes a contiguous episode block and has a fixed independent Gaussian perturbation.
3. Retrieve a prefix sum using O(log T) tree nodes; use its noisy statistics in an optimistic value-iteration update.
4. Save the tree and policy history so future deletion can reuse randomness.

For tabular RL the statistic dimension is

\[
d=HSA(S+2)=2HSA+HS^2A.
\]

Training-time tree overhead is O(d log T) per episode; tree memory is O(Td) (p. 7). These are substantial costs and should be counted in experimental comparisons.

### During deletion (Algorithm 3, pp. 6–7)

Replace x_t by the dummy's statistic x'_t, traverse leaf-to-root, and change each affected node's clean mean from v to v'. For its already sampled noisy value y, accept reuse with probability

\[
\min\{1, f_{N(v',\sigma^2I)}(y)/f_{N(v,\sigma^2I)}(y)\}.
\]

If accepted, the same noisy prefix can still support unchanged later policies. If rejected, use a Gaussian reflection coupling, `y' = v + v' - y`, and retrain the dependent suffix. The mapping reflects about the midpoint of the two means. The output law is correct after both branches; the acceptance branch is not an approximate shortcut.

The full tree construction is only approximately maximal as a global coupling; individual Gaussian node couplings are maximal. This is why the tree-level rerun bound carries an extra logarithmic factor compared with the best possible distributional coupling.

## 4. Paper results and their limits

Assumption 3.2 (p. 7) requires bounded replacement sensitivity:

\[
\sup_{t,z,z',w_{1:t}}\|EO_t(z;w_{1:t})-EO_t(z';w_{1:t})\|_2\leq B.
\]

Theorem 3.3 chooses

\[
\sigma=\frac{B\sqrt{\log_2 T}}{\sqrt{2}\rho}.
\]

It states exact unlearning, rho-TV stability, and a rerun bound of order rho sqrt(log T). Although the theorem prose says the rerun probability “is” rho sqrt(2 log_2 T), its proof (pp. 15–16) establishes an upper bound. Probabilities must also be capped at one. Interpreting cost requires adding unavoidable node-update work:

\[
\mathbb E[C_U]\lesssim O(d\log T)+\min\{1,O(\rho\sqrt{\log T})\}\,C_{\rm full\ retrain}.
\]

This is an upper bound using full retraining to upper-bound suffix reruns; individual requests can still require a long suffix rerun. It is not a measured wall-clock speedup, and the paper provides no experiments.

Theorem 4.1 (p. 8), for the stated tabular optimistic learner, gives with probability at least 1-delta:

\[
R(T)\leq\widetilde O\left(H^2\sqrt{SAT}+H^3S^2A+\frac{H^{5/2}S^2A}{\rho}\right).
\]

The three terms are the sample-learning term, a burn-in term, and the price of making the learner stable. R(T) is cumulative online regret, not a post-deletion forgetting score.

Theorem 4.4 (pp. 8–9) gives a lower bound

\[
\Omega\left(H\sqrt{SAT}+\frac{HSA}{\rho}\right).
\]

The upper/lower comparison leaves factors H and H^(3/2)S in the main terms (p. 9), in addition to logarithms and the burn-in term. Describe it as a regret–stability tradeoff with unresolved polynomial gaps, not a fully matching minimax result. As always, lower-bound parameter regimes must be compatible with the trivial maximum regret HT; “any rho” cannot be interpreted as an uncapped numeric lower bound for arbitrarily small rho and fixed T.

The paper lists as open directions: tighter regret dependence; function approximation; sublinear storage; and different mechanisms for exact unlearning (p. 9). Covariance matrices and feature summaries are explicitly suggested, so “replace counts with covariance matrices” alone is not a new research contribution.

## 5. Technical details to clarify before reproducing the paper

These are reading/implementation concerns, not claims that the entire result has been disproved.

1. **Stability output versus stored clean state.** Definition 2.2 includes metadata in the output event space (p. 5), while the tree stores clean trajectory statistics (p. 6). If those clean values are exposed as part of the TV-stability output, a changed deterministic leaf can distinguish neighboring inputs with probability one. The intended noisy transcript / private auxiliary-state distinction should be made explicit before using the theorem in an extension. Exact post-deletion state equality is a separate issue from pre-deletion TV stability.
2. **Sensitivity constant.** The p. 7 argument B <= sqrt(3H) bounds a single trajectory's statistic norm and its difference from an all-zero dummy. For arbitrary replacement by a disjoint trajectory with reward one, squared difference can be 6H; sqrt(6H) is a straightforward replacement bound. This changes constants, not the broad asymptotic direction.
3. **Terminal condition.** Algorithm 4 prints Q_(H+1)=H. Standard finite-horizon planning needs terminal V_(H+1)=0; verify the intended convention before coding.
4. **Bonus mismatch.** The bonus on p. 8 uses sqrt(S)+1, while the displayed optimism proof on p. 19 requires S+1 in the corresponding bound. Verify against author code/errata before claiming to reproduce the regret proof.

## 6. Recommended small-compute project: retained-model Bellman repair

This is a proposed project, not a theorem proved by the above paper and not a validated novelty claim.

Define the learner upfront as: fixed logged dataset -> exact additive counts/reward sums -> empirical tabular MDP with fixed data-independent priors/defaults -> canonical optimal planner with deterministic tie-breaking. This comparator makes exact trajectory removal mathematically and computationally accessible.

On deletion, subtract all the selected trajectories' statistics, then repair the changed Bellman equations using a predecessor work queue. A predecessor graph must include all actions, not only currently greedy actions. A previously suboptimal action can become optimal after deletion.

Counts subtraction exactly reconstructs the empirical MDP that full retraining on retained logs would construct. It does not by itself reconstruct an arbitrary Q-learning run's result or erase the previous critic.

For discounted gamma < 1, let T_R be the Bellman optimality operator of that exact retained empirical model, and let

\[
\eta=\|T_R Q_U-Q_U\|_\infty,\qquad\delta=\eta/(1-\gamma).
\]

The standard contraction argument gives

\[
\|Q_U-Q^*_R\|_\infty\leq\delta.
\]

Proof: add/subtract T_R Q*_R, use its gamma contraction, and rearrange. This standard lemma is not the proposed novelty.

If the gap between Q_U's largest and second-largest action values exceeds 2 delta at every relevant state, its unique greedy action agrees with the retained optimum there. This is a policy certificate. Near ties cannot be certified by this rule, so continue repair or fall back to full planning with the reference tie-breaking convention.

A conservative standard bound on the returned greedy policy's retained-model loss is 2 eta/(1-gamma)^2. In this precise setup it can be sharpened to 2 eta/(1-gamma): set V_U=max_a Q_U(s,a), observe that both the optimal Bellman residual of V_U and the policy-evaluation residual for pi_U=greedy(Q_U) are at most eta, then use contraction for both fixed points. Use whichever bound is stated and proved consistently.

### What such a certificate does not prove

- It is a numerical/control-performance certificate relative to the retained empirical model, not an (epsilon,delta) statistical-unlearning guarantee. Arbitrarily close deterministic critics can still have TV distance one.
- Exact equality of a policy-only deterministic output can follow from a strict action-gap certificate. Returning an approximate critic, old optimizer state, replay priorities, a learned encoder, or stale normalization statistics requires a separate guarantee.
- Matching the empirical retained optimum is not necessarily matching the true MDP optimum. Coverage/model error remains, especially after deleting rare transitions.
- Retained utility should be compared with the retained-only retraining baseline. Removing uniquely useful data can legitimately lower return relative to the original full-data model.

### Potential substantive contribution, requiring prior-art checks

A deletion-aware adaptive repair/fallback algorithm with a bound that depends on deleted rows, the affected predecessor subgraph, action gaps, and remaining counts/coverage; plus behavior over a sequence of deletion requests. Count all certification work in the complexity analysis. A full residual scan may already cost a full Bellman sweep, so efficient safe summaries for untouched nodes matter.

Maintain the exact current retained operator after each deletion. Then deterministic residual certificates can be applied after every request without silently accumulating old approximation error. Do not assume a statistical privacy/composition theorem follows.

Expect no uniform speedup in dense, cyclic, highly coupled MDPs. Test sparse navigation and intentionally dense/high-coupling cases, early/late deletions, random/high-influence/rare-state trajectories, and repeated deletions. Include full retained-model planning, warm-started value iteration, ordinary prioritized sweeping, and simple count subtraction + planning. Comparing only against deep-RL gradient ascent would not establish the value of a tabular local repair algorithm.

## 7. Function approximation: feasible extension and obstacles

### Safe first extension: a fixed representation and a specified model learner

For a fixed feature map phi(s,a), ridge reward/model estimation can store G = lambda I + sum phi phi^T, b = sum phi r, and C = sum phi psi(s')^T. A trajectory's contributions can be subtracted, followed by a stable solve or rank downdate. These are exact sufficient-statistic updates for the chosen regression learner. They are not novel algebra.

Use data-independent phi and psi, or pretrained features whose training data excludes all eligible deletion data. For finite next-state spaces, choosing psi as one-hot makes the transition model explicit. If regression estimates signed transition rows, use an explicitly specified deterministic projection onto the probability simplex before claiming the Bellman operator is a contraction. This construction still depends on state-space size; it is not a general continuous-state linear-MDP result.

Near-singular covariance after deletion can make downdates unstable. A coverage/conditioning check should trigger a fresh numerical factorization; all associated costs count. Fixed ridge regularization helps define a unique comparator.

### LSTD is easier but solves a narrower problem

For a fixed evaluation policy pi and fixed features, regularized LSTD uses

\[
A=\lambda I+\sum_i\phi_i(\phi_i-\gamma\mathbb E_{a'\sim\pi(\cdot|s'_i)}\phi(s'_i,a'))^\top,
\quad b=\sum_i\phi_i r_i,\quad\theta=A^{-1}b.
\]

Deleting trajectories exactly downdates A and b and reproduces the retained-data LSTD solution, assuming invertibility and the same conventions. But a pi learned from forgotten data remains contaminated; conditioning on that fixed pi is not unlearning control. LSTD matrices are generally nonsymmetric, so do not casually use positive-definite Gram-matrix guarantees for them.

### Why directly extending the paper to LSVI/deep RL is hard

- Standard fitted Q/LSVI target sums contain V_(h+1)(s'). When the value function changes, targets for retained points can change too; subtracting only deleted rows does not update all dependent targets.
- A learned shared representation changes every retained feature, Gram matrix, and target after deletion. Frozen features trained on all data retain the influence one intended to delete.
- Regression error / Bellman completeness / bounded features / covariance conditioning and exploration must be specified to prove useful regret or value bounds.
- Gaussian perturbation of covariance matrices needs positive-definite stabilization, careful sensitivity, and optimism analysis. Plugging matrices into a prefix sum is not the whole theorem.
- Online future data changes with past policies, so replayable response oracles remain necessary for an online counterfactual.

For a few-month student project, establish the tabular retained-model result and useful experiments first; fixed-feature model estimation is a stretch goal. A general exact-unlearning theorem for neural RL is not a sensible initial milestone.

## 8. Prior art the project must add to its reading list

- [TrajDeleter, NDSS 2025](https://www.ndss-symposium.org/wp-content/uploads/2025-126-paper.pdf), original [arXiv 2404.12530](https://arxiv.org/abs/2404.12530): direct offline trajectory unlearning predates the supplied exact paper. It combines forgetting and retained convergence training and introduces TrajAuditor. Lowering values on deleted states is a behavioral objective; it should not be confused with exact retraining equivalence.
- [TOUR, July 23 2026 preprint](https://arxiv.org/abs/2607.21111): trajectory partitioning, retraining references, retained utility, matched nonmembers, multiple membership audits. Its existence makes a benchmark-only “first trajectory deletion study” claim untenable.
- Prioritized sweeping / incremental dynamic programming are foundational prior art for local Bellman repair, e.g. the standard [Sutton–Barto textbook](https://www.incompleteideas.net/book/bookdraft2018mar21.pdf). The research contribution must be deletion-specific guarantees or tradeoffs beyond reusing this algorithm.
- The exact paper itself cites Zhou 2022, *Differentially Private Reinforcement Learning with Linear Function Approximation*. Any stable linear-RL extension should compare its matrix/noise/optimism techniques with that literature.

Searches here did not establish a complete absence of prior work on LSTD deletion, covariance downdates, or Bellman repair for unlearning. Absence in these queries is not evidence of novelty.
