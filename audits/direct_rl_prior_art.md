# Direct RL unlearning prior-art audit

Checked: 29 September 2026. Scope: deletion of logged experience, trajectories, users, environments, and learned behaviors in sequential decision making. This is a source-based novelty audit, not a completeness guarantee. Titles and abstracts in papers are treated as author claims; acceptance status is reported only when a primary venue or the arXiv record supports it.

## Executive finding

The present implementation plan has a valid *problem definition* but a weak novelty claim if the contribution remains “subtract deleted trajectory counts, run local prioritized Bellman backups, inspect a global residual and action gap, fall back to full planning.” Count subtraction is elementary for empirical MDPs; predecessor propagation is [prioritized sweeping](https://people.eecs.berkeley.edu/~pabbeel/cs287-fa15/optreadings/MooreAtkeson-1993-prioritized-sweeping.pdf), with [small backups](https://proceedings.mlr.press/v28/vanseijen13.html) an established refinement. The residual-to-value and action-gap arguments are standard fixed-point reasoning. Moreover, a global residual scan costs Ω(SA) Bellman-row evaluations per request, so the present certificate does not establish sublinear work even when the queue is small. A new theorem would need to exploit the *support, magnitude, and reachability* of the deletion perturbation, prove when a sparse certificate suffices, include its audit/index costs, and show a lower-bound or hard case when full propagation is necessary.

Two 2026 sources particularly narrow a generic “adaptive” story. [Ye et al., *Unlearning Offline Stochastic Multi-Armed Bandits*](https://arxiv.org/html/2605.00638) already adaptively switches between Gaussian and rollback mechanisms by data regime and privacy budget in a sequential decision problem. [Nguyen-Tang and Arora, *Exact Unlearning in Reinforcement Learning*](https://arxiv.org/html/2606.04182) already couples a stable online learner to reuse computation or replay after failure. These do not solve fixed-log MDP trajectory deletion, but they prevent claiming adaptive switching or rollback as the core innovation.

## Gaps that survive the audit

1. **Fixed-log trajectory deletion with a reference learner specified in full.** TrajDeleter and RFF aim at suppression and audit outcomes. TOUR uses retrains as an evaluation reference, but does not provide a certified update. A tabular empirical-MDP learner can support strict output-policy equality to a retained-only run; specify whether counts, critic, tie-breaking and metadata are released.
2. **Deletion-dependent computation certificate.** The current residual bound proves correctness after a global check. A stronger result would bound the necessary work by the affected predecessor subgraph and action-margin distribution, or produce a valid per-state error envelope without rescanning all rows. This remains a hypothesis until a proof and honest complete timing ledger exist.
3. **Coverage-aware deployment decision.** Deletion can remove the only evidence for a state-action row. An empirical planner then follows a fixed empty-row rule, and its policy can match retraining while losing true-environment return. A useful paper may add a *separate* safety/coverage alarm; it must not conflate this with the unlearning certificate. UBA-ORL makes the separation especially important.
4. **Bridging beyond tabular without overclaiming.** Fixed-feature policy evaluation admits additive matrix downdates. Control changes policy-dependent targets; deep actor/critic representations change across training. Formal equivalence requires stronger assumptions. A tractable bridge could use a frozen representation and a precisely defined fitted model learner before attempting neural end-to-end claims.

## Strongest negative findings for the existing plan

- Phase 2’s local queue is a planning baseline, not a new unlearning algorithm by itself. Compare to ordinary prioritized sweeping and warm-started complete value/policy iteration.
- Phase 3’s global residual/action-gap certificate may be useful as a correctness check but is not obviously publishable as a new theorem. If it scans all rows after each request, total time may be dominated by verification, particularly in sparse/local cases.
- Phase 5’s fixed-policy feature-statistic subtraction and matrix downdate are algebraic consequences of linear least squares. It is a validation bridge, not a likely headline contribution.
- Phase 6’s IQL/TrajDeleter comparison omits RFF if diffusion policies are tested. TOUR’s IQL analysis is narrower than its DT analysis, so copying its benchmark name does not automatically make results comparable. Reproduce matched controls, attacks, retrains and data splits explicitly.
- “Policy identical to retained-data retraining” and “private deletion” are different statements. A deterministic empirical learner with released counts or critic can expose the removed data even when actions match. Conversely, a privacy audit can pass by collapse. Both sides need distinct endpoints.
- Exact retained-model behavior can preserve or reveal an unsafe retained backdoor. UBA-ORL is a concrete reason to add an adversarial stratum and a deployment-safety outcome separate from the counterfactual target.

## Recommended novelty gate before scaling GPUs

Write a theorem statement that **cannot** be obtained by directly combining count subtraction, ordinary prioritized sweeping, and a textbook Bellman residual bound. A plausible target is: given a deletion perturbation on specified empirical rows, maintain a sparse upper bound on each state-action’s value change; stop when all action preferences are provably fixed; prove the work and memory cost as a function of deletion support, graph propagation, discount and action gaps, with a construction forcing global work. Confirm that the sparse verification cost is included. If this is not achievable, reframe the paper around a rigorous empirical failure taxonomy or a stronger offline-RL model class rather than promising a new local-repair theorem.

For experiments, add three adversarial classes to the plan: (i) shared-state trajectories for which value suppression over-forgets; (ii) bottleneck and small action-gap trajectories that force long-range policy changes; (iii) camouflage/backdoor deletion inspired by UBA-ORL, scored separately for retraining fidelity and safety. Use retained-only scratch retraining under the exact same learner as the primary reference. Evaluate no-op, warm-start full planning, ordinary prioritized sweeping, TrajDeleter, retained fine-tuning, and any architecture-matched RFF implementation. Report total deletion latency, preprocessing/storage, fallback rate, return, policy disagreement and attack-suite outcomes.
